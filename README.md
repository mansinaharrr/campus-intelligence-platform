# Campus Intelligence & Real-Time Analytics Platform

A real-time campus intelligence platform that turns student reports into a live picture of campus conditions, detects events, analyzes historical activity, and predicts recurring crowd patterns.

## Stack
- Java 21 + Spring Boot + Maven
- PostgreSQL 16 + Flyway
- React + TypeScript + Vite + Tailwind CSS
- WebSockets/STOMP
- Python + FastAPI + pandas + NumPy + scikit-learn
- Docker / Docker Compose
- AWS-ready: EC2, RDS, S3, CloudWatch

## Current status
This repository is the **Phase 1 project scaffold**. It contains the complete planned structure, configuration placeholders, documentation skeleton, migration placeholders, and service entry points. Application implementation is intentionally left for the development phases.

See `docs/architecture.md`, `docs/api.md`, and `docs/interview-notes.md`.
